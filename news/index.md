## flowcluster 0.2.0

- Added
  [`aggregate_clustered_flows()`](https://hussein-mahfouz.github.io/flowcluster/reference/aggregate_clustered_flows.md)
  to create representative lines from flow clusters. This function
  calculates the weighted or unweighted centroid of the start and end
  points of the flows in each cluster, and returns an sf object with one
  line per cluster.
